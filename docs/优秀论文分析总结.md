# 2017–2023 年优秀数模论文分析总结

## 一、分析对象与方法

本次分析覆盖当前文件夹中的 278 篇优秀论文，年份为 2017–2023 年，题型覆盖 A–F。采用“全量首尾页统计 + 分层全文样本 + 页面视觉核验”的组合方式：全量统计用于识别稳定的首尾结构和方法生态；42 篇“年份 × 题型”样本用于观察章节与建模链；视觉核验用于检查摘要、公式、表格和模型图在页面中的实际组织。

需要强调：这是一组已经被筛选为优秀的论文，没有普通论文对照组，因此结论是“优秀论文中常见的可迁移做法”，不是获奖原因的因果证明。自动文本抽取也可能漏掉扫描页或公式字符，所有比例应理解为观察证据而非官方标准。

## 二、最值得迁移的共性

### 1. 论文围绕题目推进，而非围绕算法推进

多数论文按问题一、问题二等顺序组织，每一问内部再完成分析、建模、求解、结果与验证。这样写的优势是评阅者能快速核对题目要求。相反，先列“回归模型、优化模型、神经网络模型”再寻找应用位置，容易形成模型堆砌。

### 2. 摘要是压缩后的完整解题记录

分层样本中，90.5% 的摘要或前言片段出现“首先”，90.5% 出现“建立”和“求解”，85.7% 出现“最后”，76.2% 出现“针对问题”。这些信号反映出摘要常按子问题陈述：做什么、用什么、得到什么、怎样验证。代表论文还会直接报告吞吐量、误差、相关系数或模型评价指标。

### 3. 复杂模型必须嵌入清楚的逻辑链

42 篇样本中出现回归、神经网络、遗传算法、聚类、线性规划、最短路、时间序列、模拟退火、微分方程等多类方法，没有单一万能套路。可迁移的不是某个模型名，而是：先识别结构，建立透明基线，发现缺陷后再增强，并用与主张匹配的指标验证。

### 4. 公式、求解和图表紧密连接

优秀论文的模型页通常先解释约束或机制，再给数学表达；随后给算法或求解结果；图表下方立即解释结果如何回答问题。公式不是装饰，图表也不是代码输出的堆积。

### 5. 多问之间存在显式递进

常见路径包括：

- 第一问建立指标或基线，第二问扩展情景或修正偏差；
- 第一问建立解析模型，后续用仿真验证并改变参数；
- 第一问训练基础模型，第二问针对已观察到的缺陷加入注意力、多尺度或融合；
- 前一问估计关键参数，后一问将其作为优化或情景分析输入。

高质量写作会说明这些接口，同时讨论误差是否向后传播。

## 三、写作风格

### 信息密度

正文倾向于使用“针对问题—首先—建立—求解—得到—验证—最后”的任务型叙述。真正值得学习的是句子中常同时包含对象、动作、结果和指标，而不是机械模仿连接词。

### 定量表达

优先写“在某场景下，指标为多少，相对什么基线改善多少”，而非“精度很高”。数值必须附单位、样本或场景，并能在正文表格、图或计算中找到来源。

### 层级与排版

常见版面采用稳定的三级标题、编号公式、表题/图题、符号表和附录代码。清晰来自结构、留白和统一，而不是花哨配色。

### 解释而非转述

图表后的有效文字应解释趋势、原因、异常和结论边界，而不是只写“由图可知”。模型评价应与实际证据相连，如计算复杂度、误差、约束满足或灵敏度结果。

## 四、建模思路

### 第一步：验收题意

逐问提取输出、对象、范围、输入、变量、约束、指标、不确定性和验证。只有这些元素明确后，模型选择才有依据。

### 第二步：建立问题依赖

明确每问的输入和输出，检查是否存在数据泄漏、循环依赖、单位变化或误差未传播。

### 第三步：建立透明基线

预测可从线性/时间序列基线开始，优化从清楚的数学规划开始，评价从透明归一化和权重开始，机制题从守恒/状态转移开始。基线既提供可解释性，也提供改进比较对象。

### 第四步：只为明确缺陷增加复杂度

新增神经网络、元启发式、融合或注意力机制时，必须指出它修复什么缺陷，以及用何指标验证。没有诊断证据的复杂化通常只增加不可复现性。

### 第五步：让验证与结论匹配

- 预测：独立测试、基线、多指标、残差和稳定性；
- 优化：可行性、约束、目标比较、最优间隙或上下界、权重敏感性；
- 评价：方向/归一化审计、权重扰动、秩稳定性；
- 机制：量纲、边界、极限情形、观测或仿真对照；
- 仿真：重复次数、收敛、区间和解析/实测基准。

## 五、推荐文章架构

1. 摘要与关键词；
2. 问题重述；
3. 问题分析与总体路线；
4. 必要的模型假设；
5. 符号和单位；
6. 共享数据说明与预处理；
7. 按问题组织的“分析—模型—求解—结果—验证—小结”；
8. 模型评价、局限和推广；
9. 结论与建议；
10. 参考文献与附录。

结构可按题目调整，关键是每项题目要求有明确落点，每一问形成闭环，摘要和结论与正文证据一致。

## 六、对优秀论文共性的进一步补强

语料中的优秀论文并非每篇都充分处理以下问题，因此 Skill 将它们设为强制质量门槛：

- 防止训练/测试和时序信息泄漏；
- 不虚构数值、引用和代码运行结果；
- 优化解必须做硬约束审计；
- 复杂模型必须有基线或消融；
- 主观权重、阈值和关键参数必须做敏感性；
- 结论强度不能超过验证证据；
- 假设必须在局限部分重新审视；
- 正文、公式、表格、代码和摘要必须一致。

## 七、形成的 Skill

最终 Skill 以“问题分析、模型设计、论文架构、写作润色、全文审查”五种模式运行。入口规则位于 [SKILL.md](../SKILL.md)，详细建模指南、写作指南、审查量表和论文模板分别位于 `references/` 与 `assets/`。它既继承优秀论文中稳定的任务型叙事和逐问闭环，也加入更严格的证据与验证要求。
