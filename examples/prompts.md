# 示例提示词

## 新赛题全流程

```text
使用 $math-modeling-paper-coach 处理我提供的赛题和附件。先不要急着选算法：
1. 建立逐问需求矩阵，列输出、变量、约束、指标、不确定性和验证；
2. 画出各问的数据/参数依赖；
3. 提出不超过 3 条模型链，说明基线、增强条件、数据成本和风险；
4. 推荐一条并说明淘汰其他方案的理由；
5. 给出计算计划、验证计划和论文目录。
所有尚未运行的结果标记为“待计算”。
```

## 优化题

```text
使用 $math-modeling-paper-coach 把问题三写成完整优化模型。逐项定义集合、参数、决策变量、目标函数、硬约束、软约束、变量域和单位；分析线性/非线性、凸性与规模，推荐求解器、停止准则、基线和约束审计。若采用启发式算法，说明为什么精确法不合适，并设计多次运行稳定性检验。
```

## 预测题

```text
使用 $math-modeling-paper-coach 设计预测方案。先检查预测时点和特征可获得性，按时间/对象分组划分数据，建立简单基线，再决定是否需要复杂模型。给出防泄漏流程、多指标评价、残差/错误样本分析、区间估计和外推边界。
```

## 评价与排序题

```text
使用 $math-modeling-paper-coach 设计指标评价模型。核对指标定义、正负向、量纲、重复性和权重来源；至少比较一种透明基线和一种增强方法，并用权重扰动、数据重采样和秩相关检验排名稳定性。不要把“客观赋权”写成绝对客观。
```

## 机理与仿真题

```text
使用 $math-modeling-paper-coach 建立机理与仿真互证方案。列状态、参数、守恒/转移关系、边界与初值、离散方法；给解析/近似基线，再设计仿真重复次数、收敛判断、置信区间和实测/解析对照。
```

## 摘要重写

```text
使用 $math-modeling-paper-coach 重写摘要。按“总述 + 逐问的任务/方法/结果/验证 + 总结”组织；保留已核实数值和单位，不新增结果。对正文找不到依据的数值加【需核对】；控制背景篇幅，避免只列模型名。
```

## 全文技术审查

```text
使用 $math-modeling-paper-coach 审查这篇论文。先检查题目覆盖、数据泄漏、目标与约束、单位、代码一致性和结果证据；按 P0–P3 列出位置、证据、影响、修改和复核方法；再按 100 分量表评分并给出修复顺序。不要先做语言润色。
```

## 中文润色

```text
使用 $math-modeling-paper-coach 润色以下章节。保持技术含义、公式和数值不变，增强“动机—方法—结果—解释”链条。先给可直接替换的修订稿，再给位置化修改清单；对需要补算、补引文或核对代码的地方明确标记。
```
